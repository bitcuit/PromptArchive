# Taffy 작업 목록

최종 갱신: 2026-10-15

## 지금 처리

- [x] 공주·왕자를 할로윈 무도회 디자인으로 고친다. 옷 자체의 호박·박쥐·가시 장미 문양, 왕관·홀·사탕 소품, 선택형 호러 장식을 넣고 소품 없이도 할로윈 요소가 남는지 확인한다.
- [x] 큰 분류와 선택축 이름을 통일하고, 조합 원형·테마 디자인을 목록에서 구분한다. 분장 이름은 원형 · 테마 순서로 정리하고 남성 의상 이름도 실제 차림에 맞춘다.
- [x] 작은 별·초승달·장미 등 얼굴 무늬를 눈 주변에서 볼로 옮긴다.
- [x] 기존 팔레트와 의상 스타일별 색에 21색을 더하고 고정색 분장은 유지한다.
- [x] Ring을 눌렀을 때 잠근 분장·의상 칸·색이 후보 컬렉션 전환 때문에 바뀌는 오류를 수정한다.
- [x] All Costumes에 메인 분장 ☆ 고정과 한 결과의 최대 분장 수 1~3개를 추가한다. 메인 의상·필수 소품은 유지하고, 서브는 조합형 원형의 허용된 장신구만 섞는다.
- [x] 눈가리개·의료용 안대를 원형과 의상 결에 맞게 제한하고, 직접 선택·랜덤의 충돌을 다시 검사한다.
- [x] 조합형 원형 10종을 의상 결·장식 모티프와 별도 축으로 구성. 여신+별처럼 조합되게 하고 강시·설녀·오니·구미호는 직접 선택, 동아시아 랜덤은 별도 선택.
- [x] 마녀·악마·유령·천사·여신 등의 의상 결, 고스로리와 눈가리개·안대, 충돌 차단의 1차 구현.
- [x] 분장마다 약한 호러 디테일을 선택적으로 넣고, 메이드·집사의 장미 덩굴을 각 의상에 맞게 처리.
- [x] 바디페인팅·몸에 붙는 전신 수트 필터를 추가하고 드레스는 잘못 걸러지지 않는지 확인.
- [x] 배경 체크를 켜면 장소 선택이 나타나고, 끄면 출력에서 빠지는지 확인.
- [x] 2020 영화판 할리퀸 망사 스타킹을 선택과 랜덤에서 허용하고, 2016 영화판 의상도 점검.
- [x] 올드 할리우드와 80년대 에어로빅을 현재 선택 목록에서 제외.
- [x] 일반 마녀·마법사의 보관된 손수 만든 분장 실루엣을 고치고, 평범한 힙색 키워드를 제거.
- [x] 간호사·좀비 의상의 낡은 천과 절제된 피 얼룩 선택지를 보강하고, 수녀 원형을 추가한다. 의료용 적십자 표식은 쓰지 않는다.
- [x] 역병의사 가면을 필수로 하고, 가면·방독면은 원형에 맞는 후보로만 둔다.
- [x] 손수 만든 분장 단계를 선택지와 랜덤에서 빼고, 낮은 품질의 종이·골판지 소품이 활성 결과에 나오지 않게 한다.
- [x] 빨간 모자 스트리트 갈래에 눈에 보이는 할로윈 소품을 보장하고 후드와 모자 중복을 막는다.
- [x] 불필요한 레이스 고양이 귀를 일반 귀 장식으로 고친다.
- [x] 앨리스에 기운 인형·작은 피 얼룩 인형·장미·호박 사탕 주머니·초콜릿을 어울리는 소품으로 추가한다.
- [x] 거미 필터를 끄면 거미 분장과 거미 소품을 빼고 거미줄은 남긴다. 출력에는 요청한 음수 강조 태그를 붙인다.
- [x] 앨리스 옆에 붉은 여왕과 시계토끼를 별도 분장으로 추가하고, 왕관·귀·회중시계 같은 정체성 요소를 보장한다.
- [x] 마녀의 초록 얼굴 분장과 장식 큐빅을 빼고, 얼굴 무늬를 원형에 맞게 정리한다.
- [x] 마녀·악마·천사의 실제 동물을 선택지에 넣고 기존 동물 필터로 끌 수 있게 한다.
- [x] 도움말 제목을 고치고 파자마 파티의 줄 전구를 선택형 방 배경으로 옮긴다.
- [x] 위 변경의 조합·프리셋·화면·문서를 검증하고 갱신.

## 나중에 처리

- [ ] 나머지 기존 분장 전체의 핵심 실루엣과 어울리지 않는 조합을 표본 점검하고, 발견된 문제를 한 원형씩 고친다.
- [ ] 기존 에디션의 항목 구성 방식을 비교해 Taffy에 유용한 부분만 선별한다.
- [ ] 실제 이미지 생성 도구에 여러 조합을 넣어 태그 전달력을 확인한다. 생성기 코드 검사만으로 이미지 결과는 판정할 수 없다.
- [ ] 코드와 문서가 안정되면 비트킷의 Claude 규칙을 사용하는 별도 검토를 진행한다. 현재 세션에서 Claude 실행 환경은 확인되지 않았다.
