# Prompt Archive

브라우저에서만 동작하는 의상 프롬프트 생성기 시리즈입니다. NovelAI 등 이미지 생성 도구용 영어 태그 프롬프트를, 미리 정의한 의상 데이터와 조합 규칙만으로 만듭니다. 서버·AI API·계정이 없습니다.

https://bitcuit.github.io/PromptArchive/

| [Empyrean](Empyrean/) | 우주적 존재 · 천체 · 승화 | 청동 천구의 콘솔 |

## 사용 방법

설치 과정은 없습니다. 저장소를 내려받고 원하는 에디션 폴더의 `index.html`을 브라우저에서 엽니다.
